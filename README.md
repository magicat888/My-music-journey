# My Music Journey

A documentation site for my music journey — built with [Zensical](https://zensical.org).

## Local Development

```bash
# Install Zensical
pip install zensical

# Serve locally with live reload
zensical serve

# Build the static site
zensical build
```

## Deployment

This site auto-deploys to GitHub Pages via GitHub Actions on every push to `main`.

Live at: https://magicat888.github.io/My-music-journey/
